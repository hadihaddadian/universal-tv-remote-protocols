CI uses one workflow: `.github/workflows/android.yml`.
It installs Java 17 and Gradle 8.11.1, then validates the repository and protocol repository, runs unit tests, runs debug and release lint, builds both debug and release APKs, and uploads the V63 debug APK artifact. The private workflow publishes the verified protocol tree to the separate public protocol repository only after the complete verify job succeeds.

A local Gradle wrapper is intentionally not fabricated. A genuine wrapper should be generated by running the official Gradle distribution when network/tooling is available.
